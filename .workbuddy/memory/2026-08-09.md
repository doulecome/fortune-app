## 动效精修 v2（用户第三次反馈："动画还是不够好看，继续优化"）
- **最重要的发现（既有 BUG，非新增）**：`.card` 原定义就带 `animation:riseIn .6s ease both`。CSS 动画在 **fill 阶段（both/forwards）的 transform 优先级高于 inline style**，所以上一轮写的 3D 倾斜 `c.style.transform=...` **从未真正生效过**——这正是"动效不够好"的隐性原因之一。修法：覆盖为 `animation:riseIn .7s var(--e-out) backwards`（入场照旧，结束后不再占用 transform）。**通用教训：任何需要被 JS inline transform 控制的元素，其 CSS 动画绝不能用 fill-mode: both/forwards。**
- 诊断出的其余廉价点：① 自绘所有线条**同时**起笔、1.2s 齐刷刷画完 → 像"一堆线一起长"而非"一笔一笔"；② 揭幕层用 `border-top-color:transparent` 的 CSS 转圈 spinner，与水墨毫无关系，且只显示 340ms 几乎看不见；③ 大量用平庸的 `ease`，缺重量感；④ ripple 是 Material 风灰白圆。

## 动效收敛（用户第 5 次提动效："就是动画不好看，优化"）—— 关键转向：从加量到克制
