来源：官网 ufate.ai + 扒 JS bundle `/_astro/MingPathApp.B2U_T7an.js`（i18n 文案全在里面，比抓页面有效）

### 它是什么
- 2026-05 上线，Astro + React + framer-motion，AI（大模型）驱动解读
- 三个入口按"**问题类型**"组织，非术数类型：

  2. Cosmic Counsel 八字问事 — 这事跟某个人有关
  3. Full Life Reading 全盘批命 — 想看完整人生
- 定价：免费概览 / $2.99 单次 / $19.99 全盘；免注册
- 报告章节：Personality & Gifts / Career Direction / Wealth Pattern / Love & Relationships / Wellbeing Notes / Life Phase Cycles / Recent Yearly Outlook（每个都有中英双语文案，可直接参考措辞）

### 关键发现（对照本项目的缺口）
1. **招牌可视化 = 人生运势 K 线蜡烛图**：逐年开高低收画蜡烛，金线=5年均线。原生文案 "each candle carries the previous year forward, green rises, red pulls back, and the gold line shows the five-year momentum average"
   - ⚠️ **本项目八字专业档标签写着"K线全展开"，但代码里根本没有 K 线图**——流年只有 8 个 pill 文字块（年份+干支+十神+神煞），图表函数仅 `ringChart` / `enhanceChart` 两个
   - 配色注意：UFate 用西方绿涨红跌；本项目国风定位应沿用**红涨绿跌**（中国习惯）
2. **问题模板引导**：首页直接列出可点问题（"什么时候脱单""今年事业怎么走""这行适合我吗"），点击带问题跳转。本项目 0 处
3. **渐进解锁（付费墙视觉）**：运势图后半段锁住 + 引导文案。本项目不收费，但"渐进揭示"可用于默认只展示近 10 年
4. 东西方星象同屏（Chinese Zodiac + Western Zodiac 一张卡）；本项目生肖/星座分属不同面板
5. **伦理边界声明区**（Guidance, not control：不做恐吓式预测/不说命定/不施压）。本项目仅分享卡一行"仅供娱乐参考"，无正式声明区
6. 四柱详情含：干支、藏干、神煞、**十二长生**（本项项目已有，3 处）；干支关系列 合冲害刑破三合三会（项目 42 处，更全）
7. 技术栈：页面切换用 Astro **View Transitions API**（原生），组件动效 **framer-motion**（弹簧/惯性物理感）。本项目动效是手写 CSS 缓动曲线，**缺物理惯性感**——用户前 4 次反馈"动效不达标（要更慢更强更长）"，可能根因不是时长而是缺弹簧惯性
8. 历史记录分类型（八字问事历史 / 全盘批命历史）；本项目历史 16 处，无分类视图

### 结论
最值的是 ①（补齐承诺未兑现的 K 线，且是用户量化本行）+ ② ③（低成本解决"打开不知道问什么"）。不该抄：AI 大模型解读（需 key）、付费、绿涨红跌配色。

### 方法论沉淀
- 抓 SPA/客户端渲染站点：WebFetch 拿不到 → 用 curl 拿原始 HTML → 找 `astro-island component-url` 或 `_next` 资源 → 下载 JS bundle → **i18n 文案对象里藏着完整功能清单和 UI 结构**，比渲染页面更快更全

### 动效物理感（用户 4 次反馈不达标，根因假设）
手写 CSS `cubic-bezier` 无法表达过冲回弹（overshoot/bounce）→ "拉长时长"只会变慢而糊。
方案：不引 framer-motion（React 库，本项目是原生单文件），改用**阻尼谐振子数值积分生成 keyframes + Web Animations API**：
`x(t) = 1 − e^(−ζω₀t)·[cos(ω_d t) + (ζω₀/ω_d)·sin(ω_d t)]`，其中 ω₀=√(k/m)，ζ=c/(2√(km))；采样 60 帧 → `el.animate(frames,{duration,easing:'linear'})`。约 30 行，可复用于 h1Open / scrollUnfurl / fxpop。

### 动效新发现（本轮最重要）
全项目有 **11 种各不相同的 `cubic-bezier`**（.42,.08,.6,1 / .16,1,.3,1 / .2,.8,.3,1 / .5,0,.78,.36 / .22,.9,.3,1 / .14,.72,.3,1 / .12,.66,.28,1 / .16,.74,.3,1 等），每个动画单独手调 = **同一部动画里不同物体用不同重力加速度**，单体看都行、放一起不对味。framer-motion 看着统一是因全站共享 spring(stiffness/damping/mass)。
叠加前轮结论（贝塞尔数学上无法过冲，拉长时长只会变"慢而糊"）→ **两个病，一个药**：统一到阻尼谐振子 + 全站共用一套 k/c/m。
