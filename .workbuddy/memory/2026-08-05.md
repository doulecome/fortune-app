## GitHub 算命项目调研（01:28，用户问"他们怎么做"）
- 主流形态：全栈 Web 应用（React/Next 前端 + Node/Python 后端 + LLM 解读层）+ 少数 Python CLI。代表：tytsxai/bazi-master、Temp0jd/AskFate、YuchengMaUTK/fortune-teller、Rexingleung/mastra。
- 计算层：无人自推天文公式，全部调现成历法库。JS 系用 lunar-javascript（与本项目同源）；Python 系用 sxtwl 寿星天文历（秒级精度、跨度 -722~9999，比 lunar-js 更专业）；AskFate 自写 bazi.ts。计算层均为纯函数+确定性+单测。
- 核心差异（vs 玄机阁）：他们普遍"算"与"说"分离——先出结构化命理数据，再喂 LLM（DeepSeek/Claude/OpenAI，配角色人设如"陈叔/薇薇安"）做解读；抽牌随机、解读 AI 生成。我们为纯规则文本、无 LLM、离线。
- 体系更全：均含紫微斗数/奇门遁甲/六爻/梅花易数/合盘合婚/AI 追问；我们缺这些。
- 我们优势：零依赖、离线、确定性、无需 API Key、单文件即开。
- 可借鉴补强（优先级）：①浏览器本地历史记录(localStorage，零成本) ②真实塔罗牌图 ③六爻/奇门/紫微/合婚 ④可选另出一版 AI 解读（不破坏离线版）。不建议换 sxtwl（破坏单文件离线）。
